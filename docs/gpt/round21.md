使用錨點之間的對數插值，避免跳階時傷害突然暴增：
const COMBO_POINTS = [
  [0, 1],
  [10, 2],
  [20, 2.8],
  [50, 4.2],
  [100, 5.4],
  [300, 7.5],
  [1000, 9.8],
  [3000, 11.8],
  [10000, 14.5],
  [30000, 17.2],
  [100000, 21],
  [300000, 24.5],
  [1000000, 28],
] as const;

function baseComboMultiplier(combo: number): number {
  const c = Math.max(0, combo);

  for (let i = 1; i < COMBO_POINTS.length; i++) {
    const [x1, y1] = COMBO_POINTS[i];
    if (c > x1) continue;

    const [x0, y0] = COMBO_POINTS[i - 1];
    const t = x0 === 0
      ? c / x1
      : Math.log(c / x0) / Math.log(x1 / x0);

    return y0 + (y1 - y0) * t;
  }

  return Math.min(32, 28 + 1.5 * Math.log10(c / 1000000));
}

// 延續現有 comboStep = 0.1 + upgrades.combo * 0.02
export function comboMultiplier(
  combo: number,
  step = 0.1,
): number {
  const upgradeLevel = Math.max(
    0,
    Math.round((step - 0.1) / 0.02),
  );
  const upgradeScale =
    1 + 0.04 * Math.min(upgradeLevel, 10);

  return Math.min(
    40,
    1 + (baseComboMultiplier(combo) - 1) * upgradeScale,
  );
}


超過 100 萬仍可持續累積 Combo；倍率逐漸趨向上限，但不會讓數值無限膨脹。商店 Combo 升級最多計入 10 級加成；若現有存檔允許超過 10 級，應先確認補償與遷移，不能直接讓已購買的升級失效。

B2. 英文題量保留方式

- 原本剩下的 6 題轉成可選加成練習。
- 按「直接通關」立即結算；按「繼續追擊」可再練最多 6 題。
- 加成題依正常規則累積知識點與經驗，每題額外 +4 金幣，每場額外金幣最多 60。

B4. 可實作的核心邏輯
type BossKind =
  | 'normal'
  | 'elite'
  | 'mini'
  | 'big'
  | 'region'
  | 'silentKing';

const EXECUTE_RULES = {
  elite:      { combo: 300,  ratio: 0.60, streak: 5 },
  mini:       { combo: 1000, ratio: 0.60, streak: 7 },
  big:        { combo: 3000, ratio: 0.60, streak: 8 },
  region:     { combo: 100,  ratio: 0.65, streak: 10 },
  silentKing: { combo: 300,  ratio: 0.65, streak: 12 },
} as const;

function canExecute(
  kind: keyof typeof EXECUTE_RULES,
  combo: number,
  trueStreak: number,
  answered: number,
  correct: number,
  originalMin: number,
  mandatoryMechanicResolved: boolean,
): boolean {
  const r = EXECUTE_RULES[kind];

  return combo >= r.combo
    && trueStreak >= r.streak
    && answered >= Math.ceil(originalMin * r.ratio)
    && correct / Math.max(1, answered) >= 0.85
    && mandatoryMechanicResolved;
}


實作時需要把 enemy.hp === 0 與 stage.completed 分開。enemy.hp === 0 代表敵人已死；stage.completed 代表可以結算。兩者不能再被當成同一個判斷。

驗收重點： Combo 2 萬、正確率 95%、足夠真實連對的玩家，在大 BOSS 達到最低處決題量後，應看到一次明確的擊倒，而不是怪物繼續站立等剩餘題目。
