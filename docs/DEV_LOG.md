## 🔴 必要的內容（目前有效的最高原則，每次修改前都要看）

1. **好玩第一、爽度第二、英文第三。** 遊戲要給人「大方」的感覺。英文是讓角色變強、打關更輕鬆的捷徑。（2026-10 起）
2. **平衡要「全盤思考」**（2026-11-01 新增，非常重要）：
   - 不追求絕對平衡，而是在「爽、大方、順暢、好玩」之下的合理平衡：不會太簡單，也不會太難。
   - 改任何機制或數值，都要同時檢查：破關、順暢度、爽度、英文學習效果、英雄強度、機制影響的程度、各項參數、運行邏輯是否順暢、合理性與可行性。
   - **用真實玩家思考，不是理想情況**：題目難度上升後自然不會一直答對；要模擬會答錯、會失敗、會重打的玩家。
   - 不要用「練習量不夠就打不倒 BOSS」這種限制。英文真的很好的玩家，用高 combo 直接虐過簡單關卡也可以；練習量不夠就再加關卡。
   - 數字要有感：例如 combo 一萬多，傷害卻只有十幾倍，玩家會覺得 combo 沒用。
   - 重大平衡決定要和 ChatGPT 深度討論（至少五輪），再用模擬驗證。
3. **目標學習成果**：玩到 C1 區的玩家，英文至少 B2～B2+；通關一區大約等於達到那一區的 CEFR 程度。
4. **分工**：Claude 是主要製作者（決策、整合、程式、測試）；ChatGPT（對話「ENG RPG遊戲」）是同事，多外包（發想、研究、劇本、專用題目、分析）。更新的文件都要上傳給 ChatGPT，讓它知道進度。一般關卡題庫由製作人的其他同仁產出。
5. **安全規則**：不准 push 到 `main`、不准部署（除非製作人同意）；不碰金鑰；commit 前跑 `npx tsc -b`、`npx vitest run`、`npx eslint src --quiet`。
6. **介面（2026-11-01 新增）**：手機與電腦介面都要清晰好看，該有的內容都要有，而且都能操作；改版面一律三種尺寸（1366×768、1920×1080、375×812）截圖驗收。
7. **目前階段（2026-11-01）**：本地端，核心目標是「完成遊戲的基底」——題庫到位後，所有功能都能運作、機制符合設計理念、系統邏輯自洽。上線、有收入之後再擴充內容（見最下方「未來藍圖」）。
