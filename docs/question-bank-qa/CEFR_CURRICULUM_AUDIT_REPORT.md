- **手動建檔的 `vocab-rX.json` 字卡量**：僅有 **3,951 條**。
- **結論診斷**：
  1. 題庫中的語言素材、原句語境、對話與發音資源**非常充沛**，完全滿足 A1 到 C2 的各項認知需求。

## 4. 四大策略落地指引（後續擴充方向）

1. **策略一（生活情境題庫包）**：針對 A1~B2 補充「點餐、租屋、外送、機場交通、看診」高頻生活情境，確保遊戲中的英語能無縫搬到現實生活使用。
2. **策略二（動詞片語與搭配詞庫）**：將 *Phrasal Verbs*（如 *give up*, *turn down*, *put off*）作為獨立考點與字卡收納，提升中高階語感。
3. **策略三（詞族演化樹）**：在遊戲內呈現 *decide ➔ decision ➔ decisive* 等詞族進化視覺特效，提高記憶爽度。
4. **策略四（跨級螺旋抽題引擎 T13）**：已於 `QuestionData.ts` 實裝完成（60% 當前階級核心字 ＋ 25% 前區低級字螺旋升級 ＋ 15% 錯題複習），確保玩家不會在同一區域重複刷同一個字。
