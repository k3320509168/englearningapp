B. 具體方案：保留乘法樂透，但加兩道控制
我建議拿下面這個版本作為第 4 輪的候選方案 R3-M，不是直接寫進正式遊戲。
B1. 遞減乘法公式
設原生 Combo 為 \(C\)，困難題抽中的倍率為 \(m\)，倍率保留係數為：
\[
g(C)=\max\left(0.12,\ 1-\frac{\log_{10}(\max(1,C))}{16}\right)
\]

實際增加的 Combo：
\[
\Delta C=\min\left(C(m-1)g(C),\ 150000\right)
\]

答對後的新原生 Combo：
\[
C_{\text{new}}=\lfloor C+\Delta C\rfloor+1
\]

這裡有兩個限制，各自解決不同問題。

第一道：對數遞減，讓 Combo 越高，Bonus 的有效倍率越低。

第二道：單次 Bonus 最多增加 150,000 Combo，確保即使玩家已經達到百萬，也不會再因為一次 ×10 而瞬間跳到千萬、數十億。

B2. 技能 Combo 必須獨立儲存
interface ComboState {
  organicCombo: number;   // 答對 + 困難題 Bonus
  skillCombo: number;     // 技能額外增加，不參與乘法
  skillGrantedWindow: number;
  windowIndex: number;
}

function effectiveCombo(s: ComboState): number {
  return s.organicCombo + s.skillCombo;
}

function bonusMultiplier(c: number, roll: number): number {
  const retention = Math.max(
    0.12,
    1 - Math.log10(Math.max(1, c)) / 16,
  );

  return 1 + (roll - 1) * retention;
}

function applyHardBonus(
  s: ComboState,
  roll: number,
): ComboState {
  const c = s.organicCombo;
  const gain = Math.min(
    150_000,
    c * (bonusMultiplier(c, roll) - 1),
  );

  return {
    ...s,
    organicCombo: Math.floor(c + gain),
  };
}

function grantSkillCombo(
  s: ComboState,
  amount: number,
): ComboState {
  const remaining = Math.max(
    0,
    40 - s.skillGrantedWindow,
  );
  const actual = Math.min(amount, remaining);

  return {
    ...s,
    skillCombo: s.skillCombo + actual,
    skillGrantedWindow: s.skillGrantedWindow + actual,
  };
}

function onWrong(s: ComboState): ComboState {
  return {
    ...s,
    organicCombo: Math.floor(s.organicCombo * 0.5),
    skillCombo: Math.floor(s.skillCombo * 0.5),
    // 真實連對 streak 另行歸零
  };
}


skillGrantedWindow 應按實際作答次數，每八題開一個新視窗，不按 Combo 或技能施放次數計算。rally 先測 +12、valor 先測 +20，整個視窗合計最多 +40。

這樣技能本身仍然能幫玩家加傷害，但不會被下次困難題再次乘算。

C. 即時擊殺後，學習量與經驗的紙上推算
這裡有一個比 Combo 倍率更大的長期平衡風險。
C1. 強玩家的學習量可能不足以支持區域封印
以 A1 為例：
- 每區 5 張地圖、每張 20 小關。
- 強玩家即時擊殺後，假設每張地圖答 60～90 題。
- 五張地圖總作答約 300～450 題。
- 如果約 35% 為新題，則只有 105～158 題的新題曝光。
- 原本 A1 封印要求至少 360 個已學單字、300 個跨日穩定單字，外加核心文法。
即使所有新題都答對，單靠這樣的主線題量，仍不可能達到 360 個新單字知識點的目標。

這代表**「每張地圖精通 60 題」和「A1 封印 360 個已學單字」不是同一層級的保障**。

我建議重新界定：
系統	定位
即時擊殺主線	故事、戰鬥與冒險
地圖精通 60～110 題	短期可選獎勵，鼓勵更多作答
知識點複習	真正建立單字與文法熟練度
區域封印	跨日長期學習認證
高標準區域試煉	已具備程度的玩家直接證明能力

已經會 A1 的強者，不必為了證明自己會英文而被迫再答幾百道簡單題。 他可以透過高標準試煉進入下一區。

真正正在學 A1 的玩家，則從額外練習、錯題修煉、跨日複習與地圖精通補足題量。

而且新題比例也要依玩家狀態調整：已經掌握大量 A1 知識的玩家，沒有必要持續用固定 35% 的比例抽取低級新題；應優先確認尚未掌握的知識點，或推薦程度更合適的區域。
C2. 經驗 70／30 怎麼算才不會讓強者落後？
以現有 A1 的 Lv5 → Lv20 為例，需求總經驗約 3,300。

如果維持原本「主線提供目標區間約 85% 的經驗」，則主線目標是：
\[
3300\times0.85=2805\ \text{EXP}
\]

假設採用 70% 來自首次通關、30% 來自有效答題：
來源	全區目標	如何分配
100 小關首次通關	約 1,964 EXP	每小關平均約 19.6 EXP
答題與學習獎勵	約 841 EXP	依有效答題、知識點進度發放
其他副本／任務	約 495 EXP	補足剩餘成長
合計	3,300 EXP	達到預期 Lv20

這個模型比單純提高「答對一題給多少 EXP」合理，因為強者能夠快速打完主線，並且不會因答題較少而嚴重落後。

不過，需要先處理原有的擊殺 EXP、菁英 EXP、BOSS EXP：

這些現有獎勵要計入首次通關的 70%，不能額外再加一次。 否則會在改版後無意間多送大量經驗。

另外，答題 EXP 建議按真正的有效作答、知識點學習與複習進度計算，而不是任何重複題都能無限刷。可以保留少量的重打經驗，但不能讓玩家在低級地圖無限制刷到超越推薦等級。
C3. 題量下降不代表英文學習效果必然下降
真正重要的是：
- 是否學會以前不會的單字？
- 是否能在不同情境下回答同一個文法概念？
- 是否在隔天仍然答得出來？
- 聽、讀、說、寫是否都有進步？
一張地圖答 200 題卻反覆遇到已經會的單字，不一定比 80 題高品質的新題與到期複習更有效。

所以我同意取消戰鬥中的最低題數，但不能取消對有效知識點覆蓋的追蹤。這部分應由區域試煉與跨日複習驗證，而不是靠 BOSS 拖長戰鬥。

D. 其他可以靠紙上推演先發現的問題
我認為至少還有六個地方，應該在真正改遊戲前處理。
D1. 三星條件可能因即時擊殺變得更難
目前三星包含：
- 沒有隊員倒下。
- 正確率至少 85%。
- 達成區域連對要求（最高 35），或平均快答 3.5 秒內。
即時擊殺後，高戰力玩家答題更少，反而更難累積 35 次真正連對。

我用獨立答題的簡化機率模型推算：假設一張地圖答 90 題，至少出現一次連續 35 題正確的機率約為：
真實正確率	達成 35 連對機率
96%	70.3%
90%	16.0%
82%	1.0%
72%	約 0.02%

這表示一般玩家就算經過努力、沒有隊員倒下，三星仍可能幾乎拿不到。高級聽讀說寫題也不適合統一要求平均 3.5 秒。

建議： 三星仍鼓勵英文實力，但連對門檻要隨實際題量重新計算，快答條件則依題型和難度正規化。也可以提供「跨日精通」作為另一條三星路線，不能只靠連對或極速答題。
D2. 女神祝福與答錯保留 50% 的互動
目前女神祝福讓答錯只損失 30% Combo。

若一般玩家改成答錯保留 50%，則女神祝福應該是保留 70%，不是再額外乘上一個保留比例。否則可能產生過高的 Combo 保存率。

而且不論是否有祝福，真正連續答對數 trueStreak 都要在答錯時中斷。保住戰鬥 Combo 不等於英文真的答對，不能讓祝福產生假的英語熟練紀錄。
D3. 行動條可能讓高級題型受到雙重懲罰
目前題目計時 20 秒，敵人行動條也隨時間推進。

這對高級閱讀、口說、寫作可能有問題：玩家不只是答錯機率較高，還可能因正常閱讀或輸入時間較長，承受更多敵方攻擊。

我建議按題型比較「每一道有效作答平均受到幾次敵人行動」，而不是只比較每題秒數。

聽力播放、瀏覽器麥克風啟動、語音辨識等待及特殊操作選單，不應計為玩家拖延時間。高級題目可以有緊張感，但不能因題目本身需要理解，就讓英文認真作答的玩家比亂猜更吃虧。
D4. 即時擊殺會讓 BOSS 機制失去出場機會
如果強者一題就能殺死小 BOSS，連答鎖、符文、分身或最後一擊等特殊機制，可能根本不會觸發。

我認為這可以接受一部分：強玩家快速擊敗低級 BOSS，本來就是製作人希望的體驗。

但首領仍然應該有辨識度。建議將特殊機制的提示放進登場演出或首題前的戰鬥預告；玩家第一次挑戰時能知道這個 BOSS 有什麼特性。

不能為了讓機制一定觸發，又偷偷加入「HP 剩 1 強制免死」或「最後一定要再答一題」。那會重蹈最低題數的覆轍。
D5. 轉盤與召喚經濟會因通關速度改變
每張地圖第一次通過第 5、10、15、20 關，各有一次轉盤。

目前每次預期獲得約 1.1 張英雄召喚券，因此一張地圖光轉盤就約 4.4 張。

即時擊殺後，強者完成同樣地圖所需時間可能大幅縮短。雖然總獎勵沒有增加，每小時取得的召喚券、金幣和其他資源卻可能顯著提高。

我不建議因此減少轉盤次數，因為這是玩家喜歡的獎勵。

但下一輪經濟推演必須比較「每張地圖獲得多少」與「每小時獲得多少」，並確認地圖精通不能無限制重領高價值召喚券。首次獎勵只發一次的規則要維持。
D6. Combo 與養成同時變強，可能讓後期 BOSS 完全失去挑戰
你第二輪已經證明，正常養成下 C2 的一般玩家可以有很高的首過率；高養成則幾乎全面碾壓。

如果再把 1,000 Combo 從 ×9.8 提到 ×12，10,000 Combo 從 ×14.5 提到 ×20，後期強者自然會更快秒殺。

這對強玩家不一定是問題。

但要確認普通玩家到底是靠英文、裝備、主動技能，還是高倍率 Combo 打贏。如果某些技能能夠在不需要答對很多題的情況下無限維持攻擊優勢，則它們可能搶走英文系統的核心價值。

因此需要拆解實際傷害來源，不要只看總勝率。

第三輪暫定共識
這次討論最有價值的地方，是我們終於把三件不同的事情拆開：

第一，戰鬥要爽。 怪物 HP 歸零就應死亡。英文好的玩家應有明顯的戰力優勢，甚至秒殺低級 BOSS。

第二，Combo 要有夢想。 不應因害怕大數字而把所有乘法改成固定加值。百萬 Combo 可以很稀有，但必須有真正可達成的遊戲模式，技能也不能再形成失控複利。

第三，學習要有成果。 不再靠 BOSS 硬拖題數，而是以知識點掌握、跨日複習、地圖精通和區域試煉，確保英文能力能被真正驗證。

我目前偏向 R3-M：遞減分母 16、單次 Bonus 最多 +150,000、技能 Combo 獨立、答錯保留一半、提高高段傷害曲線。

但這還不是最終方案。下一輪最需要證明的是：它能否同時讓一般玩家經常看到有趣的招式，讓強玩家追求百萬傳說，又不讓正常養成的 BOSS 全部失去戰鬥意義。
