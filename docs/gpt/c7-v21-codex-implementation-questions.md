2. **分段與跨門檻**：PM文字為不落後全額、+5起0.3、超過+15為0；+1～+4暫按全額理解。若一筆獎勵由+14跨到+16，是否需截斷到+15？單純按領取前等級套倍率可能超過mastery逐圖+15驗收。需先釐清，不用加怪血掩蓋。

4. **0倍率後改給金幣/素材**：PM尚未列兌換比率與應在哪些來源套用。需避免同一筆被重複轉換；0.3倍率減少的部分是否也轉換，不能默默假定。請第二意見建議可驗證的小額方案，再記決定。
5. **副本作息必須真的答題**：素材本依現有60秒與每天上限3次，按實際抽到的題型/作答時間/正確率結束，不能固定送滿分獎勵。塔按五題至少四題對才過，保留首次獎勵與樓層進度。每3天一次塔是一次挑戰，不能默認每次通關。失敗及跨日任務均留帳。
6. **最終魔王推薦200**：理解為C2最終魔王，不是將A1～C1所有區域魔王改為200；避免修改其他關卡推薦曲線或BOSS戰力。跨區EXP預算則按上一區終點→本區終點補銜接，A1仍Lv5→20。
7. **驗收範圍**：終王前記實際等級；fast下限推薦−12、normal推薦−6，mastery上限推薦+15。逐圖連續三張低於各自已定下限要列失敗；mastery未列下限，不能自行加一個。三路線與MC分離，單種子只代表該種子；先維持BOSS不動。
