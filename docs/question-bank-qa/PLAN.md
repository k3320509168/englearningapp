# 高階題庫工作計畫與驗收紀錄

日期：2026-11-01。分支：codex/advanced-question-banks。
基底：9144de9；未複製主工作目錄 battleStore.ts 與 combo.ts 的未提交修改。

## 核心理念與用途

好玩第一、爽度第二、英文第三。英文是戰鬥增益與成長的捷徑。題庫支援主線、錯題複習、跨日知識點、區域試煉、每日素材本、時空之塔、黃金之路與鍛造。程度測驗使用獨立 diag.json，不能用練過的一般題庫冒充診斷證據。
戰鬥勝利不等於 CEFR 能力認證；5,800 題是內容容量，不是每位玩家必然完成的學習量。跟讀辨識、拼字及短選擇題無法單獨證明 C1/C2 的自由表達、長篇理解與互動能力。

難度 1/2/3 約 40/30/30%，normal/boss 約 75/25%。每個技能與牌組都需覆蓋可抽取的難度，不能把所有 difficulty 3 都放 boss 導致主線後段無題可抽。
寫作 spell/fill 各半。填空依缺字數設定難度；拼字提示要能辨識指定詞，避免中文同義詞的多解問題。口說 ans 與 speak 一致，短句 4–8 字。

## 免費且有效的產出方式

使用目前已授權的對話推理能力撰寫原創題目，不呼叫付費 API、不讀金鑰、不另購服務。程式只負責格式展開、字母挖空、選項位置平衡、去重與統計；不能靠大量換人名或套模板假裝多樣性。使用官方 CEFR 與 EVP 作為命題參考，不拷貝商業考試題。
模型與 reasoning 的實際執行設定須如實記錄；尚未啟動外部模型，不能宣稱有獨立模型審查。

## 五輪深度審查（一般題庫）

1. 教學藍圖：程度、技能、詞義、文法與主題覆蓋，找出設計衝突。
2. 語言審查：逐題自行重解，檢查唯一正解、干擾選項、繁中說明、自然搭配與英美差異。
3. 對抗審查：為其他選項找可成立的語境，檢查否定範圍、語氣、推論強度、同義詞與答案洩漏；修正後重解。
4. 實際程式模擬：正確/錯誤輸入、缺字還原、口說 fallback、選項洗牌、主線分級抽題、試煉技能配額、跨日知識點。
5. 全量驗收：分布、語意重複與近似模板、詞彙資料完整性、能力證據限制、UI 實玩與回歸檢查。每輪留下具體問題、修改與未解項目，不能只有勾選。

額外模式再獨立五輪：模式目的與題池 → 逐題內容 → 抽題與重測隔離 → 多種玩家模擬 → UI/回歸與能力聲明。模擬預設正確率不等於真實玩家提升，內容效度仍需玩家資料驗證。
