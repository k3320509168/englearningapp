## 1. 目標與不可破壞的原則

- 保留「好玩第一、爽度第二、英文第三」。角色可靠養成、裝備、援助過關；學習證據另外累積，不新增強制自由口說或寫作的主線門檻。
- 「C1 區玩家至少 B2～B2+」是待驗證的產品目標；區域名稱、角色等級、答題數與指定答案辨識不得直接換算為 CEFR 達標。
- 跟讀是指定表達復述，拼字是字形提取；兩者有價值，但不充當即興互動或篇章寫作證據。
- 保留原知識、錯題、獎勵與存檔。新能力欄位對舊資料採 unknown，不追溯升格、不清空既有熟練度。
- 原缺陷修復、全庫審核與驗收持續排程；新路徑不能成為停止修 bug 的理由。

## 4. 第一條支線如何玩

試點能力：讀／聽新限制後調整方案，並用理由回應異議。放在 B1～B2 可接觸的可選冒險中；任務顯示建議難度，不宣稱單次過關＝B2。

1. **選路**：玩家讀橋樑限重 2.5 噸與商隊當前重量 2.2 噸，選擇路線並從兩條資訊指出依據。首輪教學可提示，照有完成回饋；提示使用會記錄。
2. **改計畫**：NPC 音訊告知新添 0.6 噸貨物；玩家必須重新選路，而非沿用上題答案。文本／字幕是可用備援，但此節記成閱讀輔助，不冒稱獨立聽力。可隨時回看第一節公告，避免把限重遺忘混為英語不足。先確認 TTS 可用；不承諾所有瀏覽器離線可播。
3. **回應異議**：隊長擔心繞路太久，玩家以「立場→具體理由→替代方案」卡片組織回應。人工編寫可接受組合及解釋，同義等價選項要涵蓋。自由補寫／口述是可選延伸，立即給參考範例與完成回饋，不必等待外部評分才能通關。

上述腳本現已實作為 Adventure → 護送商隊入口；有限組卡不是自由產出評量。所有數字／條件需在同一故事一致；不可要求題外專業知識。任務沒有戰鬥行動條倒數。錯誤選擇由 NPC 給具體後果與補線索，允許修正。無麥、拒權限、無語音辨識皆可續玩。

首版先使用故事完成標記與表現回饋；若加金幣／道具，先列出來源與上限並模擬再定案。不新增可無限刷的資源。獎勵冪等鍵採 taskId＋版本的明確規則；更新文案不能重設領取資格，內容版本與獎勵版本分開。每節完成寫入支線獨立斷點；主線重玩不能覆寫支線節點，中途退出／重載／重複送出不可重獎。知識的 20h 間隔不能拿來代替獎勵領取防護。

## 5. 證據與題組資料

可選題目／任務 metadata：`objectiveId`（能力目標）、`familyId`（共同素材／解法家族）、`contextId`（情境）、`contentVersion`、`assessmentRole`（practice/check）。新增於適當型別，不改既有 QuestionSkill 或 questionKey 去重／舊存檔鍵。

作答記錄至少區分：任務／題目識別與版本、客觀作答模式、提示／答案是否暴露、字幕／重播、語音轉鍵盤、是否同題／同家族已見、作答時間及對錯。重播本身不一律判不熟練，按任務規準解讀。只記最小必要本機資料；錄音、上傳與帳號分析須另有明確同意，不預設保存原始聲音。自願匯出預設去識別化；拒錄音仍可完成任務。

不要直接從受提示的 choice 題答對推成自由口說，也不要因 `skill=speaking` 就認定真的用麥克風。新事件需由實際作答通道提供；歷史 unknown 不補造 true。事件採有界儲存與彙整，備份大小需測。

family 隔離採新試點池，不把全區現有題庫對半切，避免題量不足讓試煉無法出題。獨立檢核題不進一般複習／圖鑑／預習；作答後可給回饋，但記錄 exposure 並換平行題。重測沒有足夠新題時顯示證據不足。前端靜態資料仍可被技術使用者讀取，這是避免日常練習污染，不是安全考試或防作弊保證。

## 6. 免費且可維護的落實方式

- 人工／AI 協作離線編寫有限分支、等價答案與解析，入庫前第二位審題；運行時不需要付費 LLM。
- 既有 SRS、固定答案判定與 TTS 可沿用。ASR／TTS 的連網、語音與裝置支援依瀏覽器，提供文本備援，不宣稱完整離線語音。
- 固定分支和句組裝可以規則判分；連接詞／關鍵字命中只能描述形式，不判論點合理、篇章連貫或 CEFR。
- 開放回答先供反思、範例對照與自願匯出；自評不是能力認證。未建立外部評審流程前不能叫盲評。
- 後續若使用 LLM，只作可複核的建議評分，需用人評樣本校準；不能一個模型分數直接授予 B2+。

## 7. 驗收與停損

- 模型：同日刷同題百次不增加跨日／異情境成績；同素材換人名仍同 family；提示、字幕與鍵盤路徑標記正確；舊存檔保留原進度。
- 玩法：三節不靠全對一次過，錯誤可修正；拒麥、音訊失敗、刷新、中斷、重入皆不丟進度、不重領。
- 體驗：1366×768、1920×1080、375×812；長文、鍵盤與按鈕不互遮。viewport 驗證與實機觸控分記。
- 學習：另測未見家族與延後保持，分能力報告；未評自由表達清楚標示。字數／作答時間是設計參數，不是官方 CEFR 門檻。
- 若支線造成明顯中斷、缺少平行題、評分不可靠，先保留練習與回饋、停用能力通過宣稱；不以多發資源掩蓋問題。
