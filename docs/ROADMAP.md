# 開發路線圖

本文件記錄已與專案擁有者確認的設計決策與分階段開發計畫。每個階段在獨立的 Git 分支開發，完成並驗證後再合併回 `main`。

## 已確認的決策

| 項目 | 決策 |
|---|---|
| 遊戲引擎 | Phaser 4（企劃書原寫 Phaser 3，已更正） |
| 難度範圍 | A1~C1 五級，對應多益分數 |
| 防作弊 | 戰鬥中前端即時判定（保留打擊感），關卡結算時後端重新驗證答題紀錄才發獎勵 |
| 後端 | Supabase（Auth + PostgreSQL + Edge Functions），不另架 Express |
| 資料安全 | 經濟類資料表 RLS 只開放讀取自己的資料；寫入一律經 Edge Functions |
| 帳號 | Supabase 匿名登入（訪客）→ 之後綁定 Google；搭配 CAPTCHA 與流量限制 |
| 分班 | 適應性測驗（答對升級、答錯降級，6~8 題），玩家可往上挑戰 |
| 語音 | Web Speech API 優先，不支援時改用瀏覽器端 Whisper；句子以逐字比對 ≥ 80% 判定通過 |
| 題庫 | Gemini 生成 → 格式驗證 → 模型二次審查 → 人工抽查 → 匯入（自動化流程） |

## 階段規劃

### 第 1 階段：基礎建設與跨裝置遊玩

### 第 2 階段：學習體驗
- [x] 題目資料擴充：單字的中文、詞性、例句（vocab.ts），選擇題的文法解說（explain）；驗證腳本會檢查缺漏
- [x] 戰前情報：每 10 關開始前以卡片預習該段單字與文法，可跳過、可關閉自動顯示，戰鬥中按 📖 可重看
- [x] 關卡結算：每個 Boss 後的區段結算、全區通關與失敗時的結算（正確率、最高 Combo、一次答對的字、需加強的字）
- [x] 新手引導：首次進入自動開啟，可跳過，地圖上「❓ 說明」可重看（金幣與道具頁標示為下個版本開放）
- [x] 設定頁：語速、音量、自動發音、自動預習、麥克風測試、重看引導、重置進度
