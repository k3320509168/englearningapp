# C8 版面第一輪（進行中）

2026-11-01，工作副本 codex/advanced-question-banks。此文件是首輪證據，不表示 C8 全部驗收完成。

## 改動與目的

- 地圖上方資訊、導覽、畫布外框、征途與快捷列採同一個最大1120px內容寬；畫布依剩餘高度配置，Phaser FIT保留800×480原始內容，避免裁掉地圖旗幟。
- 桌機戰鬥框使用可用視窗高度，左右58/42，取消400px固定題目欄；場景保持等比例置中，仍有框內留邊。尚需檢視是否應調整場景本身來更充分利用此空間，不能只因外框填滿便宣稱完全沒有空白。
- 關卡名獨立完整一列，撤退與四個工具在下一列；不再刪節。主要工具最少44px。
- 作答內容有明確容器：長題文可在題卡內捲讀，四個選項採兩欄，桌機字級18px/手機16px；不把長題答案推到文件底部。
- 手機一般場景維持約三分之一高度上限，受5:3原始比例及螢幕寬度限制；長閱讀/寫作改約22dvh上限，讓出閱讀與鍵盤空間。這是對「約35%」的內容適應，並非每題固定35%。
- 窄畫面鍵盤改置作答區內，不再固定遮住題目；不以pointer:coarse決定是否提供鍵盤，窄視窗也可實測。結算的主要操作列固定在結算卡底部，長成果內容可內捲。
