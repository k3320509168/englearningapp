## 1. 劇本：B1 黃金沙漠（`regionIdx = 3`）

- **主線脈絡**：追查海岸鎖鏈上的沙漠封印 → 綠洲爭水與空白盟約 → 護送商隊識破假貨單 → 沙暴城揭穿假政令 → 古水道壁畫喚起露米記憶殘片 → 日落神殿發現法老主動交出封印術 → 突破流沙海市蜃樓，直面流沙法老。
- **英文＝真名力量**：從單句進階到「實用溝通、時程與契約」（完成式、被動、商務書信）。每修復一條契約真名，就能看穿沙漠假象、讓商隊重拾信任。
- **魔王塑造**：**流沙法老**曾被舊王國一紙背信盟約所傷，認定「文字一旦落入凡人手裡只會變成謊言」，因而與沉默君王交易：獻出沙漠古封印術（間接鎖住了深海巨獸），換取將沙漠古碑永遠封存於金字塔中。
- **新登場角色建議**：
  - `caravan`：**商隊領袖莎拉** 🐪（豪爽守信的沙漠女商頭，為空白帳冊所困）
  - `scribe`：**古碑學者阿努** 📜（熱愛古文字的年輕學者，追查消失的盟約碑）
  - `pharaoh`：**流沙法老** 👑（以封存文字為使命、高傲卻背負愧疚的沙漠古王）

## 2. 劇本：B1+ 赤岩峽谷（`regionIdx = 4`）

- **主線脈絡**：踏入回音扭曲的峽谷 → 風蝕拱門發現古代英雄誓碑 → 礦坑小鎮修復傳聲管、得知「吞聲黑鐵」與山神名碑被毀 → 峭壁與赤焰祭壇奪回殘碑（露米認出自己的校對筆跡）→ 斷崖棧道與夥伴連攜救人 → 深入石林迷陣，在龍岩深淵喚回狂暴龍岩的真名。
- **英文＝真名力量**：峽谷岩壁會扭曲零碎短句，必須用「結構嚴密的複合句與關係子句」才能精準傳聲；同時呼應遊戲的「英雄真名契約」與「連攜攻擊拉回隊友」機制。
- **魔王塑造**：**狂暴龍岩**原是守護古代英雄誓碑的山嶽巨靈，並非投靠魔王，而是被魔王軍強行鑿碎胸口的真名碑核，在劇痛與失憶中無差別砸毀北方通道。
