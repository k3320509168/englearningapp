# 第四輪設計（2026-10-29 定案）

使用者給方向，細節和 Gemini 討論後定案。原則：**好玩第一、爽度第二、英文第三**；英文是讓角色變強、打關更輕鬆的捷徑，要讓玩家覺得遊戲「大方」。
使用者授權：除了影響整體平衡的大改動，細節由 Claude 和 Gemini 討論後直接處理。

## 1. 區域與題庫 ✅
- 九區：A1、A2、A2+、B1、B1+、B2、B2+、C1、C2（新增碧藍海岸、赤岩峽谷、雷鳴高原）。
- 題庫目標：A1～A2+ 各 1000、B1／B1+ 1300、B2 1500、B2+ 1800、C1／C2 2000；聽 30%、讀 30%、說 20%、寫 20%。
- 出題：Gemini 聊天室（Chrome，3.1 Pro＋思考「低」），`scripts/chat-batch.ts`、`scripts/clip-import.ps1`，備份在 `D:\Game_q_storege`。
- API 免費額度每個模型每天 20 次（失敗也算），`generate-questions.ts` 已改成忙碌換模型、額度用完就停。
- 各區新單字量與代表文法（給出題提示詞用）：
  - A1 約 400 字：S+V+O、be 動詞與現在簡單式、in/on/at
  - A2 約 500 字：過去簡單式、現在進行式、比較級與最高級
  - A2+ 約 500 字：未來式 going to／will、情態動詞 can/must/should、頻率副詞
  - B1 約 600 字：現在完成式、If 第一類條件句、被動語態基礎
  - B1+ 約 600 字：過去進行式、關係代名詞、動名詞與不定詞
  - B2 約 700 字：過去完成式、If 第二／三類、間接引語
  - B2+ 約 700 字：現在完成進行式、複雜被動、情態動詞推測 must have done
  - C1 約 800 字：分詞構句、倒裝句、強調句
  - C2 約 800+ 字：假設語氣、慣用語、動詞片語
- 專屬題庫（之後做）：世界王詠唱句 50～100 句、每位英雄真名短篇故事（100～150 字）、程度測驗錨點題 150～200 題。
- 防膩：同一題答對 5～7 次就畢業；錯誤選項可從同級字庫動態抽換；同一個字用不同題型多次曝光。

## 2. 關卡與首領 ✅（第一版）
- 一般關連續 5 隻怪（每隻 1～2 擊）；菁英 8～10 題；守門頭目 12～15 題；區域魔王 20～25 題。
- 三星：無人倒下＋正確率 85%＋最大 combo 達該區門檻（8→35）或平均 3.5 秒內。
- 首領「連擊破甲」：combo 未達門檻只打 10%；門檻 A1 15 → B2 60 → C2 100（守門頭目 6 成）；combo 整張地圖延續進首領戰。
- 魔王祝福：首領戰答錯 combo 只扣 30%。一般關失敗 1 次 50%、2 次必定得到「女神的祝福」（不斷 combo、傷害 +20%）。

## 3. 敵人主動攻擊 ✅
- A1、A2：只在答錯時反擊。
- A2+、B1：每 4 題一次主動攻擊。前一題顯示「蓄力中」；5 秒內答對可打斷並讓敵人暈眩（下一題受傷 +50%）；超過 5 秒答對承受 1.0×；答錯 1.5× 並斷 combo。
- B1+、B2：每 3 題一次「重擊蓄力」。答對仍受 0.5×（戰士格擋或護盾技能可無傷）；答錯 2.0×。
- B2+、C1、C2：每 3 題，首領另有無預警瞬發攻擊；「必殺蓄力（2 回合）」需連續 2 題都 3 秒內答對，或施放 2 個主動技能才能打斷；被打到 3.0×。

## 4. 首領技能 ✅（九區魔王＋守門頭目／菁英共用技能池 5 招）
區域最終魔王（各區主題）：
- A1 巨型樹精【瘋狂生長】每 3 題補血 10%；火屬性攻擊或 5 combo 可禁療。
- A2 幻影魔女【視覺剝奪】隱藏下一題 2 個選項文字，答對後魔女破防（受傷 200%）。
- A2+ 深海巨獸【海嘯沖刷】打亂技能能量；前一題預告，護盾技能或極速答對可擋。
- B1 流沙法老【海市蜃樓】召喚 2 個假分身，答錯被重擊；刪去選項類技能或連對 2 題看破。
- B1+ 狂暴龍岩【大地碎裂】震飛一名隊員 2 題（不能出手）；連攜攻擊可救回。
- B2 冰霜巨龍【極寒領域】答題時間縮短為 8 秒、持續 3 題；延長時間技能或 20 combo 抵消。
- B2+ 雷暴獅鷲【靜電標記】連續答錯時受到的傷害 30%→100%→200% 疊加。
- C1 炎魔之王【灰燼炸彈】倒數 3 題，期間要答對至少 1 題拼寫題才能拆除並反炸。
- C2 沉默君王【全知封印】封印所有技能，達到 50 combo 解封並進入 Fever Time。

守門頭目／菁英共用技能池（隨機 1～2 招）：時光小偷（每題 -5 秒）、硬化護甲（只吃暴擊或剋制）、單字貪吃鬼（母音變底線）、狂暴化（HP < 30% 答錯必擊倒一人）、屬性折射（隨機免疫 3 屬性）、吸血鬼（攻擊回血 50%）。

## 6. 技能系統擴充 ✅（9 種被動天賦、5 種連攜技）
每位角色：1 主動＋1 被動天賦＋參與連攜技。
- 被動天賦（數值 R／SSR）：
  - 輸出：殘血狂化（HP < 30% 攻擊 +20/50%）、Combo 共鳴（每 10 combo 攻擊 +5/15%）、巨人殺手（對首領 +15/35%）、弱點看破。
  - 防禦：鋼鐵意志（受擊 10/30% 機率減半）、元素抗性、重生（死亡時 10/30% 機率復活一次）、不屈。
  - 治療／控制：吸血（傷害 5/15% 轉血）、能量泉源（開場能量 +1/3）、緩速（敵人蓄力 +1/2 題）、急救。
  - 英文輔助：學霸視角（錯題本的題目錯誤選項半透明，每場 1/3 次）、字根透視（拼寫題顯示首尾字母，SSR 解鎖）、靈光一閃（2 秒內答對 combo +1/+2）、運氣大師（最後 3 秒答對 20/50% 能量回滿）。
- 連攜技：4 人輪一輪觸發，依最後出手的職業決定：劍士 無盡劍陣 300%、戰士 絕對城壁 150%＋全隊 15% 護盾、弓箭手 流星箭雨 200% 必暴、魔法師 元素核爆 400%、僧侶 神聖洗禮 100%＋全隊回 20% HP 並清除負面狀態。
- 推薦流派：極速風暴流（雙弓＋劍士＋詩人）、學霸逃課流（戰士＋雙法＋先知）、不倒翁流（雙戰士＋牧師＋劍士）、元素接力爆發流（三屬性法師＋主教）。
