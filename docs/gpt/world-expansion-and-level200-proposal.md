# 第一張大地圖的成長收尾與未來擴充：交 Claude 審查

日期：2026-11-01。狀態：Codex 提案與待討論事項，非 Claude 已同意的結論，不取代 balance-r5-final-spec.md。

## 製作人最新方向

九個大區域可視為一張「大地圖」。未來可以新增大地圖，提供更深入、不同領域的英文，或其他語言與學習內容。現有等級問題可以討論是否暫留，但能合理到200等更好；目的是長期好玩、持續回來玩，同時英文進步。此要求授權設計與協作，不代表立即實作第二世界、加等級上限或改整體平衡。

## 現況與不能混淆的數字

C9 SEED7 四種玩家經濟準備路徑在 C2 終王前為 Lv142～146，已能走到該處；不是實測玩家普遍卡關，也不是完成地圖精通後的等級。尚未實作 C7 新經驗池，未納入所有副本或三種遊玩路線，不據此認定現有內容一定不足。

依 growth.ts 的 xpToNext(lv)=100+10*lv，從各級零當級經驗到200需要：142為104690、143為103170、145為100100、146為98550 EXP；190為20450、195為10350。實際缺口還要扣當級已有EXP。這是算式上界，不是要求直接補發的數量。不能用總EXP倍率等比例反推等級。

先完成 C4→C5→C6→C7，保留目前BOSS數值與Lv200上限。現有v2.0經驗池先照規格實作，三路線重跑後再決定差額處理，不先更改已定85%預算或70/30分配。

|---|---|---|

|先照C7校準，完整遊玩路線可達200，快速路線容許較低|不同玩家都有選擇，能以精通與複習承接持續遊玩|需區分有意義的可選內容與強迫刷題，並重新驗收各路線|

Codex傾向第三個候選，尚待Claude討論。若要放寬原本快速路線的推薦等級差驗收，需明確修訂規格；目前不得自行把不達標改稱合格。

200是第一世界完整養成的候選里程碑，不是前往下一區的必要條件，也不是英文能力證書。若一般正常遊玩仍差很多，優先查首通獎勵、學習補貼資格與來源分帳，而非臨時要求玩家重刷低階怪。

## 長期內容如何接上學習

- 近期沿用既有地圖精通、到期複習、塔與支線，讓玩家可在「推主線／回顧錯題／挑戰」之間選擇。需量測內容與獎勵是否足夠，不能把既有入口數量當可玩性證據。
- 到200之後仍可用英雄搭配、真名故事、專武與挑戰紀錄提供目標；哪些已有完整內容、哪些只是藍圖，要在正式設計時分清。角色滿等後的EXP去向需另定，不在本提案自行改兌換。
- 深入英文可走不同情境的推論、語域、立場、聽讀整合與自由產出，而非只增加罕用詞。職場、科學、公民議題、文化藝術均可作未來內容候選，不以C2後虛構CEFR更高級別。
- 新語言需獨立程度診斷、知識點、語音與文字輸入支援；既有角色可保留，但英文成績不得直接變成新語言精通證明。較高戰力的跨世界銜接需另測，避免新語言內容直接被戰力略過。
- 延續既有「英文讓遊戲更輕鬆、擊殺不被題數攔住」原則。精通與複習給可見回報，但不把所有玩家每日上線或重做同題當必要條件。

## 實驗與接受條件

- 連續A1 Lv5→C2，不注入等級或資源、不重置知識／裝備；快速、正常、精通三路線與四玩家模型，分開記錄終王前及通關後。
- 每圖輸出等級、EXP來源、有效／重複答題、獨特知識、複習間隔、耗時、失敗重打與資源帳。C9固定一圖一天只是模型假設；另測一天多圖及非每天遊玩，不能把61圖等同真實61日留存。
- 同種子可重現，再以多種子檢查抽卡與掉落敏感度；門檻沿用當時正式規格，不挑最好看的路線交付。
